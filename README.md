# Task Manager REST API

A beginner-friendly REST API built with Java and Spring Boot. It lets you create, view, update, and delete tasks.

## Features

- Create a task
- Get all tasks
- Get a task by ID
- Update a task
- Delete a task
- Validate that task titles are not blank

## Tech Stack

- Java 21
- Spring Boot
- Spring Web
- Maven
- Jakarta Bean Validation

## Requirements

- JDK 21
- Maven (or use the Maven wrapper generated by your IDE)

## Run the project

From the project root, run:

```bash
mvn spring-boot:run
```

The API starts at `http://localhost:8080`.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/tasks` | Get all tasks |
| GET | `/api/tasks/{id}` | Get one task |
| POST | `/api/tasks` | Create a task |
| PUT | `/api/tasks/{id}` | Update a task |
| DELETE | `/api/tasks/{id}` | Delete a task |

## Example: Create a task

Send a `POST` request to `http://localhost:8080/api/tasks` with this JSON body:

```json
{
  "title": "Learn Spring Boot",
  "completed": false
}
```

Example response:

```json
{
  "id": 1,
  "title": "Learn Spring Boot",
  "completed": false
}
```

## Example: Get all tasks

Send a `GET` request to `http://localhost:8080/api/tasks`.

## Important note

This starter version stores tasks in memory. Tasks are cleared when the application restarts. A database can be added as a next step.
